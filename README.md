# homebrew-tap

Homebrew Tap for [3062-in-zamud](https://github.com/3062-in-zamud) tools.

## Usage

```bash
brew tap 3062-in-zamud/tap
brew install ai-multi-review
```

## Tools

| Formula | Description |
|---------|-------------|
| [ai-multi-review](https://github.com/3062-in-zamud/ai-multi-review) | Multi-LLM parallel code review CLI |
